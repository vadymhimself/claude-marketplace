How to get your own key

  1. Be eligible: real name, full address with apartment number, a profile photo, a verified payment method, and a passed Upwork identity check.
  2. Apply on Upwork's API page. Do not rush a sloppy application, it can trigger a new identity check.
  3. Pick one permission scope and write a clear reason that matches it. A human reviews it.
  4. Once approved, enable the rest of the scopes. No new request needed.
